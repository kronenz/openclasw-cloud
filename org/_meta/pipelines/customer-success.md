# customer-success 파이프라인

## 개요
고객 활동 분석, 리인게이지먼트, 리포트 생성, 업셀 추천을 통해 고객 성공을 지원하는 파이프라인.

**담당 팀**: Customer Success Team
**실행 방식**: 주기적(주간/월간) + 이벤트 기반
**자동화 수준**: 반자동 (분석은 자동, 액션은 일부 수동)
**우선순위**: P2 (장기 관계 관리)

## 트리거

### 주기적 트리거
- **주간 (월요일 09:00)**: 활동 분석, 리인게이지 대상 식별
- **월간 (1일 00:00)**: 종합 리포트, 업셀 분석

### 이벤트 트리거
- **7일 미사용**: 리인게이지 캠페인
- **한도 80% 도달**: 업셀 제안
- **이탈 신호**: 사용량 급감 (전주 대비 50% 감소)
- **성공 신호**: 사용량 급증 (전주 대비 200% 증가)

### 수동 트리거
- 고객 요청 (맞춤 리포트)
- CS 팀 직접 실행

## 단계

### 1. 고객 활동 분석 (주간/월간)
**AI 에이전트**: `scientist`, `product-analyst`

**입력**
- 테넌트 사용량 데이터 (operations 파이프라인)
- 대화 로그 (D1)
- 스킬 사용 내역

**작업**
1. **활동 메트릭 계산**
   ```typescript
   interface TenantMetrics {
     tenant_id: string;
     period: '7d' | '30d';

     // 참여도
     active_users: number; // 대화한 사용자 수
     total_conversations: number;
     avg_conversations_per_user: number;

     // 사용 패턴
     peak_hours: string[]; // 가장 활발한 시간대
     top_skills: { skill: string, count: number }[];
     avg_response_time: number; // AI 응답 시간

     // 만족도 (추정)
     positive_feedback_rate: number; // 👍 비율
     completion_rate: number; // 대화 완료율
     retry_rate: number; // 재질문 비율 (낮을수록 좋음)

     // 비즈니스
     plan: string;
     usage_vs_limit: number; // 한도 대비 사용률 (%)
     cost_per_conversation: number;
   }
   ```

2. **세그먼트 분류**
   - **Champions** (활발 + 만족): 활동 많음 + 긍정 피드백 높음
   - **At Risk** (저조 + 불만): 활동 감소 + 부정 피드백
   - **Potential Upsell**: 한도 80% 이상 사용
   - **Need Attention**: 7일 미사용
   - **Happy Inactive**: 만족하지만 사용 안 함 (추후 재활성화 대상)

3. **인사이트 생성**
   - 업종별 벤치마크 (동일 업종 평균과 비교)
   - 트렌드 (증가/감소/정체)
   - 이상 패턴 (갑작스런 변화)

**산출물**
- 테넌트별 메트릭 (D1 저장)
- 세그먼트 분류
- 인사이트 리포트

### 2. 리인게이지먼트 캠페인 (이벤트: 7일 미사용)
**AI 에이전트**: `writer`, `executor`

**입력**
- "Need Attention" 세그먼트 테넌트
- 테넌트 메타데이터 (업종, 스킬)

**작업**
1. **원인 추정**
   - 초기 설정 미완료 (페르소나/연동 없음)
   - 기대 불일치 (AI 응답 품질)
   - 경쟁사 전환
   - 계절적 요인 (업종별)

2. **맞춤 메시지 생성**
   ```markdown
   안녕하세요, [고객사명] 담당자님.

   OpenClaw 팀입니다. 최근 1주일간 서비스 사용 기록이 없어 연락드립니다.

   혹시 불편하신 점이나 개선이 필요한 부분이 있으신가요?
   저희 팀이 도와드리겠습니다.

   📌 추천 기능:
   - [업종별 맞춤 스킬] 설치하시면 [구체적 효과]
   - [연동] 설정으로 [편의 기능] 활용 가능

   30분 상담 예약: [링크]

   감사합니다.
   ```

3. **멀티채널 발송**
   - 이메일 (1차)
   - 슬랙 DM (연동된 경우, 2차)
   - SMS (3일 무응답 시, 3차)

4. **팔로업**
   - 응답 시: CS 팀 직접 상담
   - 무응답 14일: "Happy Inactive" 세그먼트 이동 (월 1회 뉴스레터만)

**산출물**
- 발송 로그
- 응답률 (목표: 30%)

**Human Gate**
- 대량 이탈 (10개 이상 동시) → 시스템 이슈 의심
- 주요 고객 (Enterprise 플랜) → 직접 전화

### 3. 주간/월간 리포트 생성 (주기적)
**AI 에이전트**: `writer`, `scientist`

**입력**
- 테넌트 메트릭
- 대화 로그 샘플 (대표 사례)

**작업**
1. **리포트 구성**
   ```markdown
   # [고객사명] OpenClaw 주간 리포트
   기간: 2026-02-01 ~ 2026-02-07

   ## 요약
   - 총 대화: 1,250건 (+15% vs 지난주)
   - 활성 사용자: 8명
   - 가장 인기 스킬: FAQ 검색 (450회)
   - 평균 만족도: 4.5/5.0

   ## 주요 인사이트
   📈 **증가 추세**: 주문 조회 스킬 사용 2배 증가
      → 고객 문의 감소 효과 (CS 팀 업무 경감)

   💡 **추천 액션**:
      - "배송 추적" 스킬 추가 시 추가 30% 문의 감소 예상

   ## 대표 대화 사례
   [고객 질문] "환불 절차 알려줘"
   [AI 응답] "환불은 주문 후 7일 이내 가능합니다. [단계별 안내]"
   [결과] ✅ 완료 (추가 문의 없음)

   ## 다음 주 목표
   - 배송 추적 스킬 설치 (무료)
   - 피크 타임(14-16시) 응답 속도 개선

   ---
   문의: support@openclasw.cloud
   ```

2. **시각화**
   - 대화량 추이 차트
   - 스킬 사용 분포 (파이 차트)
   - 시간대별 활동 (히트맵)

3. **발송**
   - 이메일 (PDF 첨부)
   - 대시보드 (웹, 실시간 업데이트)

**산출물**
- 주간/월간 리포트 (PDF)
- 대시보드 업데이트

### 4. 업셀 기회 분석 및 제안 (월간 + 이벤트)
**AI 에이전트**: `product-analyst`, `writer`

**입력**
- "Potential Upsell" 세그먼트
- 플랜별 한도 정보

**작업**
1. **업셀 트리거**
   - **한도 80% 도달**: 자동 업그레이드 제안
   - **유료 스킬 3개 이상 사용**: 상위 플랜이 경제적
   - **사용자 10명 이상**: 팀 플랜 추천
   - **월간 대화 10,000건 이상**: Enterprise 제안

2. **ROI 계산**
   ```typescript
   // Basic → Pro 업그레이드 시
   current_cost = $30/월;
   overage_cost = (사용량 - 한도) * $0.05; // 초과 비용
   pro_cost = $100/월;

   if (current_cost + overage_cost > pro_cost) {
     recommend_upgrade = true;
     savings = (current_cost + overage_cost) - pro_cost;
   }
   ```

3. **맞춤 제안**
   ```markdown
   안녕하세요, [고객사명] 담당자님.

   좋은 소식입니다! 🎉
   OpenClaw 활용도가 매우 높으시네요. (상위 10%)

   현재 Basic 플랜 한도의 85%를 사용 중이시며,
   이대로 진행 시 이번 달 초과 비용이 약 $40 예상됩니다.

   💰 Pro 플랜으로 업그레이드 시:
   - 월 $100 (고정, 초과 비용 없음)
   - 한도 10배 증가 (10k → 100k 대화/월)
   - 프리미엄 스킬 5개 무료 포함
   - **예상 절감: $30/월**

   지금 업그레이드: [링크]
   상담 예약: [링크]
   ```

4. **발송 및 팔로업**
   - 이메일 (자동)
   - 응답 시: 계약 팀 연결
   - 7일 무응답: 1회 리마인더

**산출물**
- 업셀 제안 로그
- 전환율 (목표: 20%)

**Human Gate**
- 대규모 할인 (20% 이상)
- 커스텀 플랜 (표준 플랜 외)

### 5. 이탈 방지 (이벤트: 사용량 급감)
**AI 에이전트**: `analyst`, `writer`

**입력**
- "At Risk" 세그먼트
- 부정 피드백 로그 (👎, 불만 표현)

**작업**
1. **위험 신호 감지**
   - 사용량 50% 급감 (전주 대비)
   - 부정 피드백 3회 이상 (주간)
   - 고객 지원 티켓 증가
   - 계약 갱신 60일 이내 (플랜 변경 가능 시점)

2. **원인 분석**
   - 로그 분석 (어떤 질문에서 실패했는지)
   - 경쟁사 비교 (기능 부족)
   - 고객 업종 변화 (페르소나 부적합)

3. **선제 대응**
   - CS 팀 직접 연락 (전화/미팅)
   - 맞춤 개선안 제시
   - 필요 시 커스터마이징 (무료, 이탈 방지 목적)

**산출물**
- 위험 고객 리스트
- 대응 이력

**Human Gate (필수)**
- 모든 "At Risk" 고객은 Operator 리뷰
- 보상/할인 제안 승인

### 6. 성공 사례 수집 (월간)
**AI 에이전트**: `writer`, `product-analyst`

**입력**
- "Champions" 세그먼트
- 긍정 피드백 로그
- ROI 데이터 (CS 팀 업무 시간 절감 등)

**작업**
1. **성공 메트릭 추출**
   - CS 응대 시간 감소 (%)
   - 고객 만족도 상승
   - 비용 절감 (자동화 효과)

2. **케이스 스터디 작성**
   ```markdown
   # [고객사명] 성공 사례: CS 응대 시간 60% 감소

   ## 배경
   중소 이커머스 기업 [고객사명]은 월 5,000건의 고객 문의를 처리하며
   CS 팀 3명이 상시 근무 중이었습니다.

   ## 도입
   OpenClaw AI 비서를 도입하여 FAQ, 주문 조회, 배송 추적을 자동화했습니다.

   ## 결과
   - CS 응대 건수: 5,000 → 2,000건 (60% 감소)
   - 평균 응답 시간: 5분 → 30초 (90% 단축)
   - 고객 만족도: 3.5 → 4.5 (CSAT)
   - 연간 절감: CS 인력 1명 = 약 $30,000

   ## 고객 인터뷰
   "OpenClaw 덕분에 CS 팀이 단순 문의 대신 복잡한 케이스에 집중할 수 있게 되었습니다."
   - [담당자명], [직책]
   ```

3. **활용**
   - 마케팅 자료 (웹사이트, 블로그)
   - 영업 제안서 (유사 업종 고객에게)
   - 고객 동의 후 공개

**산출물**
- 케이스 스터디 (월 1-2건 목표)
- 고객 인터뷰 (선택)

```
[세그먼트별 액션]

  ├─ At Risk → 이탈 방지 (직접 상담)
  ├─ Potential Upsell → 업셀 제안
  ├─ Need Attention → 리인게이지
  └─ Happy Inactive → 월간 뉴스레터

```

## 고객 세그먼트

| 세그먼트 | 정의 | 액션 | 우선순위 |
|---------|------|------|---------|
| Champions | 활동 많음 + 만족도 높음 | 성공 사례 수집, 추천 요청 | P3 |
| At Risk | 활동 감소 + 불만 | 직접 상담, 개선안 제시 | P0 |
| Potential Upsell | 한도 80% 이상 | 업그레이드 제안 | P1 |
| Need Attention | 7일 미사용 | 리인게이지 캠페인 | P2 |
| Happy Inactive | 만족하지만 미사용 | 월간 뉴스레터 | P3 |
| New | 온보딩 30일 이내 | 온보딩 가이드, 튜토리얼 | P1 |

## 성공 메트릭

### 리텐션
- **월간 활성률**: 85% (목표: 90%)
- **이탈률**: 5%/월 (목표: 3%/월)
- **재활성화율**: 25% (리인게이지 캠페인)

### 업셀
- **업셀 전환율**: 15% (목표: 20%)
- **평균 업그레이드 금액**: $70/월

### 만족도
- **NPS (Net Promoter Score)**: 45 (목표: 60)
- **CSAT (Customer Satisfaction)**: 4.3/5.0 (목표: 4.5/5.0)

### 효율
- **리포트 생성 시간**: 자동 (목표: 5분)
- **CS 팀 응답 시간**: 24시간 (At Risk 고객)

## 에러 처리

### 데이터 부족
- 신규 고객 (7일 미만): 최소 데이터로 기본 리포트
- 저활동 고객: "활동 부족으로 인사이트 제한적" 안내

### 이메일 발송 실패
- 재시도 (3회)
- 대체 채널 (슬랙, SMS)

### 잘못된 세그먼트 분류
- 고객 피드백 수집 ("이 메시지가 적절하지 않으셨다면...")
- 머신러닝 모델 재학습

## 최적화 전략

### 개인화 강화
- 업종별 맞춤 메시지
- 사용 패턴 기반 추천 (스킬, 연동)

### 예측 분석
- 이탈 예측 모델 (30일 전 사전 대응)
- 업셀 타이밍 최적화 (언제 제안할지)

### 자동화 확대
- 리인게이지 응답 자동 분류 (긍정/부정/중립)
- A/B 테스트 (메시지 톤, 제목)

## 통합

### 입력 (from)
- **operations**: 사용량 데이터, 메트릭
- **tenant-provisioning**: 신규 고객 정보
- **integration-setup**: 연동 완료 고객
- **incident-response**: 장애 영향 고객

### 출력 (to)
- **고객**: 리포트, 이메일, 리인게이지 메시지
- **Operator**: 이탈 위험 알림, 성공 사례
- **sales**: 업셀 전환 고객 (계약 팀)

### 사용 서비스
- **Cloudflare D1**: 메트릭, 세그먼트 저장
- **Cloudflare Workers**: 리포트 생성, 이메일 발송
- **Cloudflare R2**: 리포트 PDF 저장
- **외부**: SendGrid (이메일), Twilio (SMS)

## 개인정보 보호

### 데이터 최소화
- 익명화된 메트릭만 수집 (대화 내용은 제외)
