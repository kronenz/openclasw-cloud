# operations 파이프라인

## 개요
플랫폼의 일상적인 운영 및 모니터링을 담당하는 파이프라인. 헬스체크, 비용 관리, 로그 분석을 자동화하여 안정적인 서비스 제공.

**담당 팀**: Platform Team
**실행 방식**: 크론 (5분/1시간/일일 주기)
**자동화 수준**: 완전 자동 (예외 시만 Human Gate)
**우선순위**: 연속 실행 (백그라운드)

## 트리거

### 크론 스케줄
- **5분 주기**: 헬스체크, 긴급 알림 확인
- **1시간 주기**: 비용 추적, 사용량 분석
- **일일 (00:00 UTC)**: 종합 리포트, 백업, 로그 아카이브

### 이벤트 트리거
- 에러율 급증 (5% 초과)
- 비용 한도 도달 (일일/월간 80%)
- 성능 저하 (응답 시간 2배 증가)

## 단계

### 1. 헬스체크 (5분 주기)
**AI 에이전트**: `qa-tester`

**작업**
1. **테넌트별 헬스 상태 확인**
   - 모든 활성 테넌트 Worker에 `/health` 요청
   - 응답 시간, HTTP 상태 코드 수집
   - D1, KV, R2 접근성 확인

2. **임계값 검증**
   - 응답 시간 <200ms (정상), <500ms (경고), >=500ms (위험)
   - 에러율 <1% (정상), <5% (경고), >=5% (위험)

3. **자동 조치**
   - 위험: incident-response 파이프라인 즉시 트리거
   - 경고: 로그 수집 + 모니터링 강화 (1분 주기로 전환)
   - 정상: 다음 5분 주기 대기

**산출물**
- 헬스 상태 JSON (D1 저장)
```json
{
  "timestamp": "2026-02-08T12:00:00Z",
  "total_tenants": 150,
  "healthy": 148,
  "warning": 2,
  "critical": 0
}
```

**알림**
- Slack (Operator 채널): Critical 발생 시 즉시
- 이메일: 1시간 내 복구 안 되면 에스컬레이션

### 2. 비용 추적 및 최적화 (1시간 주기)
**AI 에이전트**: `scientist`, `architect`

**작업**
1. **비용 데이터 수집**
   - Cloudflare Analytics API
     - Workers 실행 시간 (CPU ms)
     - AI Gateway 요청 수 (토큰 사용량)
     - D1 쿼리 건수
     - R2 스토리지 사용량
   - 외부 서비스 (Stripe, SendGrid 등)

2. **테넌트별 비용 계산**
   ```typescript
   cost_per_tenant =
     (workers_cpu_ms / 1000000 * $0.02) +
     (ai_gateway_requests * $0.001) +
     (d1_queries / 1000 * $0.01) +
     (r2_storage_gb * $0.015)
   ```

3. **한도 검증**
   - **일일 한도**: 플랜별 (Basic: $1/일, Pro: $10/일, Enterprise: $100/일)
   - **월간 한도**: 플랜별 (Basic: $30/월, Pro: $300/월, Enterprise: $3000/월)

4. **자동 다운그레이드** (한도 80% 도달 시)
   - **1단계**: Opus → Sonnet (AI Gateway)
   - **2단계**: Sonnet → Haiku
   - **3단계**: 요청 쓰로틀링 (10 req/min 제한)
   - 고객에게 이메일 알림 + 업그레이드 제안

5. **비용 최적화 제안**
   - 사용하지 않는 리소스 식별 (7일 미사용 Worker)
   - 중복 데이터 제거 (R2 중복 파일)
   - 캐싱 기회 (반복 쿼리)

**산출물**
- 비용 리포트 (D1 저장, 대시보드 표시)
- 최적화 제안 (Operator 리뷰용)

**Human Gate**
- 월 비용 예산 초과 (계획 대비 20% 이상)
- 대규모 최적화 (Worker 재구조화 등)

### 3. 로그 분석 (1시간 주기)
**AI 에이전트**: `scientist`, `debugger`

**작업**
1. **로그 수집**
   - Cloudflare Workers Logs (지난 1시간)
   - 에러 로그 (500, 502, 503, 504)
   - 경고 로그 (Rate Limit, Timeout)

2. **패턴 분석**
   - 에러 빈도 (에러 코드별)
   - 느린 엔드포인트 (P95 >1초)
   - 이상 트래픽 (갑작스런 증가)

3. **근본 원인 추론**
   - 반복 에러: 코드 버그 가능성 → debugger 에이전트 분석
   - 특정 테넌트: 리소스 부족 → 업그레이드 제안
   - 전체 플랫폼: 인프라 이슈 → Operator 에스컬레이션

4. **자동 조치**
   - 반복 에러 (10회 이상): incident-response 트리거
   - 성능 저하: 캐싱 강화, CDN 설정 조정

**산출물**
- 로그 분석 리포트 (R2 저장)
- 근본 원인 추론 (Operator 리뷰용)

### 4. 사용량 모니터링 (1시간 주기)
**AI 에이전트**: `scientist`

**작업**
1. **사용 패턴 분석**
   - 활성 사용자 수 (MAU, DAU)
   - 대화 건수 (테넌트별, 시간대별)
   - 인기 스킬 (호출 빈도)

2. **이상 탐지**
   - 갑작스런 사용 증가 (평소 대비 10배)
   - 장기 미사용 (7일 이상 대화 없음)
   - 비정상 패턴 (반복 요청 = 봇 의심)

3. **인사이트 생성**
   - customer-success 팀에 전달
     - 리인게이지 대상 (7일 미사용)
     - 업셀 대상 (한도 80% 사용)
     - 이탈 위험 (사용량 감소 추세)

**산출물**
- 사용량 리포트 (customer-success 전달)
- 이상 알림 (Operator)

### 5. 일일 종합 리포트 (24시간 주기, 00:00 UTC)
**AI 에이전트**: `writer`, `scientist`

**작업**
1. **메트릭 집계**
   - 전체 테넌트 수 (신규, 활성, 비활성, 이탈)
   - 총 요청 수, 성공률, 에러율
   - 총 비용 (플랫폼, 테넌트별)
   - 인시던트 수 (해결/미해결)

2. **리포트 생성**
   ```markdown
   # OpenClaw Cloud 일일 운영 리포트
   날짜: 2026-02-07

   ## 요약
   - 활성 테넌트: 150개 (신규 +5)
   - 총 요청: 1,250,000건 (성공률 99.8%)
   - 총 비용: $450 (예산 대비 90%)
   - 인시던트: 2건 (모두 해결)

   ## 주요 이벤트
   - 10:30 UTC: tenant-abc Worker 응답 지연 → 자동 재시작 (해결)
   - 15:45 UTC: AI Gateway Rate Limit 도달 (tenant-xyz) → Opus→Sonnet 다운그레이드

   ## 권장 조치
   - tenant-xyz: Pro 플랜 업그레이드 제안
   - 7일 미사용 테넌트: 15개 (리인게이지 필요)
   ```

3. **배포**
   - Operator 이메일 발송
   - 대시보드 업데이트 (Cloudflare Pages)

**산출물**
- 일일 리포트 (PDF, 이메일)
- 대시보드 (웹)

### 6. 백업 및 아카이브 (24시간 주기)
**AI 에이전트**: `executor`

**작업**
1. **D1 백업**
   - 모든 테넌트 D1 스냅샷 (Cloudflare D1 Backup API)
   - R2에 저장 (보관 기간: 30일)

2. **로그 아카이브**
   - Workers Logs → R2 (압축)
   - 보관 기간: 6개월

3. **메타데이터 백업**
   - 테넌트 설정, 스킬 설정, OAuth 토큰 (암호화)
   - R2에 저장 (보관 기간: 1년)

4. **백업 검증**
   - 랜덤 테넌트 선택 (3개)
   - 백업 복원 테스트 (임시 환경)

**산출물**
- 백업 파일 (R2)
- 백업 검증 리포트

## 자동 스케일링

### 리소스 확장
- **Workers**: 자동 (Cloudflare 관리)
- **D1**: 용량 80% 도달 시 확장 제안 (수동 승인)
- **R2**: 자동 확장 (Cloudflare 관리)

### 비용 제어
- **Opus → Sonnet**: 일일 한도 80% 시
- **Sonnet → Haiku**: 일일 한도 95% 시
- **쓰로틀링**: 일일 한도 100% 시 (긴급)

## 알림 정책

### P0 - 즉시 (Slack + 이메일 + SMS)
- 플랫폼 전체 장애 (10개 이상 테넌트 동시 에러)
- 보안 침해 의심 (이상 트래픽 패턴)

### P1 - 5분 이내 (Slack + 이메일)
- 개별 테넌트 Critical 상태
- 비용 한도 100% 도달

### P2 - 1시간 이내 (이메일)
- 경고 상태 지속 (1시간 이상)
- 비용 한도 80% 도달

### 일일 요약 (이메일)
- 정상 운영 시 매일 리포트

## 데이터 플로우

```
[크론 트리거: 5분]
    ↓
[헬스체크] → [임계값 검증]
    ├─ 정상: 대기
    ├─ 경고: 모니터링 강화
    └─ 위험: incident-response 트리거

[크론 트리거: 1시간]
    ↓
[병렬 실행] ─┬─ [비용 추적]
             │    ├─ 비용 계산
             │    ├─ 한도 검증
             │    └─ 자동 다운그레이드
             │
             ├─ [로그 분석]
             │    ├─ 에러 패턴
             │    ├─ 근본 원인 추론
             │    └─ 자동 조치
             │
             └─ [사용량 모니터링]
                  ├─ 패턴 분석
                  ├─ 이상 탐지
                  └─ customer-success 전달

[크론 트리거: 24시간]
    ↓
[병렬 실행] ─┬─ [종합 리포트]
             │    └─ Operator 발송
             │
             └─ [백업/아카이브]
                  ├─ D1 스냅샷
                  ├─ 로그 아카이브
                  └─ 백업 검증
```

## 성공 메트릭

### 가용성
- 목표: 99.9% (연간 다운타임 <8.76시간)
- 현재: 99.5%

### 성능
- 평균 응답 시간: <200ms (목표: <150ms)
- P95: <500ms (목표: <300ms)
- P99: <1000ms (목표: <500ms)

### 비용 효율
- 테넌트당 평균 비용: $3/월 (목표: $2.5/월)
- 플랫폼 전체 비용: $450/일 (150 테넌트)

## 최적화 전략

### 비용 절감
- AI Gateway 캐싱 강화 (반복 질문 = 캐시 히트)
- D1 쿼리 최적화 (인덱스 개선)
- R2 라이프사이클 정책 (30일 이상 미사용 파일 삭제)

### 성능 개선
- Worker Cold Start 감소 (예열 크론)
- CDN 캐싱 전략 (정적 응답)
- 지역별 리전 최적화 (아시아 트래픽 → 서울 리전)

### 자동화 확대
- 자동 복구율 향상 (현재 80% → 목표 95%)
- 예측 스케일링 (머신러닝 기반 사용량 예측)

## 통합

### 입력 (from)
- **모든 파이프라인**: 헬스 상태, 로그, 메트릭
- **Cloudflare**: Analytics, Logs, Billing API

### 출력 (to)
- **incident-response**: 장애 감지 시 트리거
- **customer-success**: 사용량 인사이트 전달
- **Operator**: 일일 리포트, 알림

### 사용 서비스
- **Cloudflare Analytics**: 메트릭 수집
- **Cloudflare Workers Logs**: 로그 분석
- **Cloudflare AI Gateway**: 사용량 추적
- **Cloudflare D1**: 상태 저장
- **Cloudflare R2**: 백업, 로그 아카이브
- **외부**: Slack (알림), SendGrid (이메일)

## 보안

### 접근 제어
- Analytics API: 읽기 전용 토큰
- 백업: 암호화 (AES-256)

### 감사 로그
- 모든 자동 조치 기록 (다운그레이드, 재시작 등)
- 보관 기간: 1년

- 현재 비용 소진율 (일일/월간)
- 최근 인시던트 (24시간)

### 트렌드 뷰
- 7일/30일 사용량 추이
- 비용 추세

### 알림 센터
- 미해결 알림 목록
