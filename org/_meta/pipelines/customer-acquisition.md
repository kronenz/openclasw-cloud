# customer-acquisition 파이프라인

## 개요
리드 유입부터 계약 체결까지 전체 영업 프로세스를 관리하는 파이프라인.

**담당 팀**: Sales Team
**평균 소요 시간**: 3-7일
**자동화 수준**: 반자동 (계약/가격은 Human Gate)
**우선순위**: P1 (계약 단계), P2 (상담 단계)

## 트리거

### 자동 트리거
- 웹사이트 문의 폼 제출
- 데모 요청 버튼 클릭
- 채팅 상담 요청
- 제휴사 리드 유입 (웹훅)

### 수동 트리거
- Operator가 직접 리드 등록 (오프라인 미팅, 전화 문의 등)

## 단계

### 1. 리드 수집 및 분류 (자동)
**AI 에이전트**: `analyst`

**입력**
- 리드 정보 (이름, 회사, 이메일, 전화, 문의 내용)
- 유입 경로 (웹사이트, 광고, 제휴사 등)

**작업**
- 리드 스코어링 (0-100점)
  - 회사 규모 (직원 수, 추정 매출)
  - 업종 (적합도)
  - 긴급도 (문의 내용 분석)
  - 예산 (명시된 경우)
- 리드 분류: Hot(70+점), Warm(40-69점), Cold(<40점)
- CRM 등록 (Cloudflare D1)

**산출물**
- 리드 프로필
- 스코어링 결과
- 추천 액션 (즉시 전화, 이메일 발송, 나중에 연락 등)

### 2. 초기 상담 및 요구사항 분석 (반자동)
**AI 에이전트**: `analyst`, `writer`

**입력**
- 리드 프로필
- 초기 문의 내용

**작업**
- 상담 일정 자동 조율 (이메일/문자)
- 상담 준비 자료 생성
  - 고객 업종 분석
  - 유사 사례 조사
  - 예상 질문 목록
- 상담 진행 (Operator 또는 자동 챗봇)
- 요구사항 정리
  - 사용 목적
  - 예상 사용자 수
  - 필요 연동 (카카오톡, 슬랙 등)
  - 특수 요구사항

**산출물**
- 상담 기록
- 요구사항 문서
- 다음 단계 추천

**Human Gate**
- 복잡한 커스터마이징 요청 (표준 기능 외)
- 대규모 엔터프라이즈 (100인 이상)

### 3. 제안서 작성 및 데모 (자동)
**AI 에이전트**: `writer`, `product-manager`, `executor`

**입력**
- 요구사항 문서
- 고객 정보

**작업**
- 제안서 자동 생성
  - 고객 맞춤 솔루션 설명
  - 기대 효과 (ROI 추정)
  - 구현 일정
  - 견적 (표준 가격표 기준)
- 데모 환경 구축
  - 임시 테넌트 생성 (1주일 유효)
  - 샘플 페르소나 구성
  - 데모 시나리오 준비
- 제안서 발송 (이메일)
- 데모 일정 조율

**산출물**
- 제안서 PDF
- 데모 환경 URL
- 데모 가이드

**Human Gate**
- 표준 가격표 이탈 시 (할인 10% 초과)
- 커스텀 요금제 요청

### 4. 계약 협상 (수동)
**AI 에이전트**: `analyst` (조언 제공)

**입력**
- 제안서
- 고객 피드백

**작업**
- 계약 조건 협상
  - 가격 조정
  - SLA 합의
  - 구현 범위 확정
- 계약서 생성 (템플릿 기반)
- 법무 검토 (필요 시)

**산출물**
- 최종 계약서
- 가격 확정

**Human Gate (필수)**
- 모든 계약 최종 승인 (Operator)
- 표준 SLA 변경
- 특수 조건 추가

### 5. 결제 처리 (자동)
**AI 에이전트**: `executor`

**입력**
- 서명된 계약서
- 결제 정보

**작업**
- 결제 링크 발송 (이메일/문자)
- 결제 처리 (Stripe/Toss Payments 연동)
- 결제 확인 웹훅 수신
- 다음 파이프라인 트리거 (tenant-provisioning)

**산출물**
- 결제 완료 확인서
- tenant-provisioning 파이프라인 시작 이벤트

## 데이터 플로우

```
[리드 유입]
    ↓
[CRM 등록] (Cloudflare D1)
    ↓
[리드 스코어링]
    ↓
[상담 일정 조율] → [상담 진행] → [요구사항 문서]
    ↓
[제안서 생성] → [데모 환경 구축]
    ↓
[데모 발송]
    ↓
[계약 협상] → [Human Gate: 계약 승인]
    ↓
[결제 처리]
    ↓
[tenant-provisioning 트리거]
```

## Human Gate 정책

### 즉시 에스컬레이션
- 연 매출 1억 이상 대형 고객
- 법적 리스크 (특수 계약 조건, 데이터 주권 등)
- 가격 할인 10% 초과

### 24시간 내 검토
- 표준 SLA 변경 요청
- 커스텀 기능 개발 필요 판단
- 제휴 제안

### 주간 리뷰
- Cold 리드 처리 방향
- 전환율 분석
- 가격 정책 조정 필요성

## 성공 메트릭

### 전환율
- 리드 → 상담: 60%
- 상담 → 제안: 80%
- 제안 → 계약: 40%
- 전체: 19.2% (리드 → 계약)

### 소요 시간
- 리드 → 상담: 1일
- 상담 → 제안: 1-2일
- 제안 → 계약: 3-5일
- 전체: 평균 5일 (목표: 3일)

### 품질 지표
- 고객 만족도 (상담): 4.5/5.0
- 제안서 적합도: 80% (고객 피드백)
- 계약 후 이탈률: <5% (첫 3개월)

## 에러 처리

### 일반 에러
- 상담 일정 조율 실패 → 수동 연락 (Operator)
- 데모 환경 구축 실패 → incident-response 파이프라인 트리거
- 결제 실패 → 고객에게 재시도 안내 + Operator 알림

### 이탈 처리
- 제안 후 7일 무응답 → 자동 팔로업 이메일
- 제안 후 14일 무응답 → Operator에게 알림 (수동 연락 판단)
- 제안 후 30일 무응답 → 리드 상태 변경 (Warm → Cold)

## 최적화 전략

### 자동화 확대
- 챗봇 상담 정확도 향상 (FAQ 학습)
- 제안서 템플릿 고도화 (업종별, 규모별)
- 가격 추천 엔진 (리드 스코어 기반)

### 전환율 개선
- Hot 리드 우선 처리 (응답 속도 30분 이내)
- 업종별 성공 사례 확보 (케이스 스터디)
- 데모 품질 향상 (시나리오 다양화)

### 병목 해소
- 계약 승인 프로세스 간소화 (표준 계약은 자동 승인)
- 제안서 생성 시간 단축 (템플릿 + AI 활용)

## 통합

### 입력 (from)
- 웹사이트 (문의 폼, 채팅)
- 마케팅 캠페인 (광고, 이메일)
- 제휴사 시스템 (웹훅)

### 출력 (to)
- **tenant-provisioning**: 결제 완료 시
- **CRM** (Cloudflare D1): 모든 리드/상담/계약 정보
- **customer-success**: 계약 고객 정보 전달

### 사용 서비스
- Cloudflare D1: CRM 데이터베이스
- Cloudflare Workers: 웹훅 처리, 이메일 발송
- Cloudflare R2: 제안서 PDF 저장
- 외부: Stripe/Toss Payments (결제), SendGrid (이메일)
