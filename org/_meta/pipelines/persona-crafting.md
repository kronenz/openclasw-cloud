# persona-crafting 파이프라인

## 개요
고객 비즈니스에 맞는 AI 비서 페르소나를 설계하고 SOUL.md를 생성하는 파이프라인.

**담당 팀**: Persona Team
**평균 소요 시간**: 30분 (고객 응답 제외)
**자동화 수준**: 반자동 (복잡한 커스터마이징은 Human Gate)
**우선순위**: P2 (품질 중요, 24시간 이내)

## 트리거

### 자동 트리거
- **tenant-provisioning 완료** (주 트리거)

### 수동 트리거
- 페르소나 재구성 요청 (고객 또는 CS 팀)
- 업종 변경, 비즈니스 모델 변화 시

## 단계

### 1. 설문 수집 (반자동, 고객 응답 시간 제외 시 5분)
**AI 에이전트**: `analyst`, `writer`

**입력**
- 테넌트 정보 (업종, 회사명, 플랜)
- 계약 시 수집한 요구사항

**작업**
1. **맞춤형 설문 생성**
   - 업종별 템플릿 (제조, 유통, 서비스업 등)
   - 비즈니스 모델 (B2B, B2C, B2B2C)
   - 사용 목적 (고객 응대, 내부 업무 자동화, 마케팅 등)

2. **설문 항목**
   - AI 비서 역할 (예: 고객 상담사, 영업 어시스턴트, HR 담당자)
   - 톤 앤 매너 (격식, 친근함, 전문성 등)
   - 주요 태스크 (FAQ 응대, 일정 관리, 문서 작성 등)
   - 금기 사항 (특정 주제 회피, 민감 정보 처리 규칙)
   - 연동 희망 서비스 (카카오톡, 슬랙, 이메일 등)

3. **설문 발송**
   - 이메일 + 테넌트 대시보드 링크
   - 응답 마감: 48시간 (미응답 시 기본 페르소나 적용)

**산출물**
- 설문 응답 JSON
```json
{
  "role": "고객 상담사",
  "tone": "친근하고 공손함",
  "tasks": ["FAQ 응대", "주문 조회", "환불 안내"],
  "avoid_topics": ["가격 협상", "기술 지원"],
  "integrations": ["kakao", "slack"]
}
```

### 2. SOUL.md 생성 (자동, 10분)
**AI 에이전트**: `writer`, `analyst`

**입력**
- 설문 응답
- 업종별 베스트 프랙티스 (내부 DB)

**작업**
1. **페르소나 정의**
   - 이름, 역할, 성격 (설문 기반)
   - 전문성 영역 (업종 지식)
   - 응대 스타일

2. **SOUL.md 작성**
   ```markdown
   # AI 비서 페르소나

   ## 기본 정보
   - 이름: [고객사명] 어시스턴트
   - 역할: 고객 상담사
   - 성격: 친근하고 공손하며 문제 해결 지향적

   ## 톤 앤 매너
   - 존댓말 사용
   - 이모지 적절히 활용 (😊, ✅ 등)
   - 간결하고 명확한 표현

   ## 주요 태스크
   - FAQ 응대 (배송, 반품, 교환)
   - 주문 조회 및 상태 안내
   - 환불 절차 안내

   ## 금기 사항
   - 가격 협상은 담당자 연결
   - 기술 지원은 전문팀 연결
   - 개인정보 요구 시 보안 확인 절차

   ## 지식 베이스
   - 회사 소개
   - 제품 카탈로그
   - 배송 정책
   - 반품/교환 정책
   ```

3. **지식 베이스 초기 구성**
   - 고객 제공 자료 (PDF, 문서 등)
   - 웹사이트 크롤링 (FAQ, 정책 페이지)
   - 벡터 임베딩 (Cloudflare Workers AI)

**산출물**
- SOUL.md 파일 (테넌트 R2 저장)
- 지식 베이스 임베딩 (Vectorize)

### 3. 스킬 선택 및 구성 (반자동, 10분)
**AI 에이전트**: `executor`, `analyst`

**입력**
- 설문 응답 (주요 태스크)
- 플랜 정보 (포함 스킬)

**작업**
1. **추천 스킬 목록 생성**
   - 태스크 기반 자동 추천
   - 예: FAQ 응대 → "FAQ 검색 스킬", 일정 관리 → "캘린더 스킬"

2. **스킬 설치**
   - 무료 스킬: 자동 설치
   - 유료 스킬: 플랜 포함 여부 확인 → 자동 설치 또는 업셀 제안

3. **스킬 설정**
   - 파라미터 설정 (예: 캘린더 스킬 → Google Calendar OAuth)
   - 권한 설정 (어떤 역할이 사용 가능한지)

**산출물**
- 설치된 스킬 목록
- 스킬 설정 JSON (D1 저장)

**Human Gate**
- 커스텀 스킬 개발 필요 (마켓플레이스에 없음)
- 유료 스킬 추가 요청 (플랜 외)

### 4. 테스트 대화 및 검증 (반자동, 5분)
**AI 에이전트**: `qa-tester`

**입력**
- SOUL.md
- 설치된 스킬
- 테스트 시나리오

**작업**
1. **자동 테스트 시나리오 실행**
   - 기본 인사 ("안녕하세요")
   - FAQ 질문 ("배송 기간이 얼마나 걸리나요?")
   - 스킬 호출 ("오늘 일정 알려줘")
   - 예외 처리 ("욕설 입력", "개인정보 요구")

2. **품질 검증**
   - 톤 앤 매너 일관성
   - 지식 베이스 활용 여부
   - 스킬 정상 작동
   - 응답 시간 (<2초)

3. **고객 승인 요청**
   - 테스트 대화 로그 공유
   - 수정 요청 수집
   - 최대 3회 수정 가능 (그 이상은 Human Gate)

**산출물**
- 테스트 리포트
- 고객 승인 여부

**Human Gate**
- 3회 수정 후에도 만족하지 못하는 경우
- 복잡한 커스터마이징 요청 (다중 페르소나, 시나리오별 톤 변경 등)

### 5. 배포 및 완료 (자동, 1분)
**AI 에이전트**: `executor`

**입력**
- 최종 승인된 SOUL.md
- 스킬 설정

**작업**
1. **프로덕션 배포**
   - SOUL.md → 테넌트 R2
   - 스킬 설정 → D1
   - Worker 환경 변수 업데이트

2. **고객 안내**
   - 페르소나 완료 이메일
   - 다음 단계 안내 (integration-setup)
   - 사용 가이드 링크

3. **메타데이터 업데이트**
   - CRM 상태 변경 (프로비저닝 → 페르소나 완료)
   - integration-setup 파이프라인 트리거

**산출물**
- 배포 완료 알림
- integration-setup 파이프라인 시작

## 데이터 플로우

```
[tenant-provisioning 완료]
    ↓
[설문 생성 및 발송] → [고객 응답 대기]
    ↓
[SOUL.md 생성]
  ├─ 페르소나 정의
  ├─ 톤 앤 매너
  ├─ 태스크/금기사항
  └─ 지식 베이스 (벡터 임베딩)
    ↓
[스킬 선택]
  ├─ 추천 스킬
  ├─ 자동 설치 (무료/플랜 포함)
  └─ 설정
    ↓
[테스트 대화]
  ├─ 자동 시나리오
  ├─ 품질 검증
  └─ 고객 승인 요청
    ↓
[배포] → [integration-setup 트리거]
```

## 템플릿

### 업종별 SOUL.md 템플릿
- **이커머스**: 고객 상담사, 주문/배송/반품 전문
- **제조업**: 기술 지원 어시스턴트, 제품 문의 전문
- **서비스업**: 예약 관리 어시스턴트, 일정/FAQ 전문
- **교육**: 학습 가이드, 코스 안내 전문
- **의료**: 접수/예약 어시스턴트 (진단/처방 금지)

### 톤 앤 매너 프리셋
- **격식**: 존댓말, 이모지 최소, 전문 용어 사용
- **친근**: 존댓말 + 이모지, 쉬운 표현
- **캐주얼**: 반말 가능, 이모지 적극 활용 (B2C 서비스)
- **하이브리드**: 상황별 톤 변경 (고객 불만 → 격식, 일반 문의 → 친근)

## 에러 처리

### 설문 미응답
- 48시간 후 자동 리마인더 (1회)
- 72시간 후 기본 페르소나 자동 적용 + 고객에게 "나중에 수정 가능" 안내

### SOUL.md 생성 실패
- 템플릿 폴백 (업종별 기본 템플릿)
- Operator에게 알림 (수동 검토)

### 스킬 설치 실패
- 해당 스킬 건너뛰기
- 고객에게 "일부 스킬 설치 실패, CS 팀이 연락 예정" 안내

### 테스트 실패
- 자동 재시도 (SOUL.md 미세 조정)
- 3회 실패 → Human Gate (Persona Team 수동 개입)

## 성공 메트릭

### 품질
- 고객 1차 승인률: 80% (목표: 90%)
- 평균 수정 횟수: 1.5회 (목표: 1회)
- 배포 후 7일 내 재구성 요청률: <10%

### 효율
- 평균 소요 시간: 30분 (고객 응답 제외)
- 자동화율: 70% (Human Gate 30%)

## 최적화 전략

### 템플릿 고도화
- 업종별 베스트 프랙티스 DB 구축
- 성공 케이스 학습 (GPT-4 fine-tuning)

### 설문 간소화
- 현재 10개 질문 → 5개 핵심 질문
- 나머지는 AI가 추론 (회사 웹사이트, CRM 데이터 기반)

### 실시간 협업
- 고객이 대시보드에서 실시간 SOUL.md 편집 가능
- AI가 실시간 제안 (Copilot 스타일)

## 통합

### 입력 (from)
- **tenant-provisioning**: 프로비저닝 완료 이벤트
- **customer-acquisition**: 계약 시 수집한 요구사항
- **고객**: 설문 응답

### 출력 (to)
- **integration-setup**: 페르소나 완료 이벤트
- **R2**: SOUL.md 저장
- **D1**: 스킬 설정 저장
- **Vectorize**: 지식 베이스 임베딩

### 사용 서비스
- **Cloudflare Workers AI**: 임베딩 생성
- **Cloudflare Vectorize**: 지식 베이스 벡터 DB
- **Cloudflare R2**: SOUL.md 저장
- **Cloudflare D1**: 스킬 설정, 테스트 로그
- **외부**: SendGrid (설문/완료 이메일)

## 보안 및 윤리

### 금기 페르소나
- 의료 진단, 법률 자문, 금융 투자 조언 (전문 면허 필요)
- 아동/청소년 대상 부적절 콘텐츠
- 정치/종교적 편향 (중립 유지)

### 데이터 프라이버시
- 지식 베이스는 테넌트별 완전 격리
- 고객 데이터는 학습에 사용 안 함 (옵트인 방식)

### 편향 완화
- SOUL.md에 "공정성, 다양성 존중" 기본 포함
- 차별적 언어 필터링
