## 담당 파이프라인
- **P-008: 고객 성공 파이프라인**

## 주요 업무

### 활동 분석가 (A-CSM-001)
- 고객별 AI 에이전트 사용 빈도 분석
- 스킬 활용률 측정
- 미사용 기능 식별
- 이탈 위험 고객 탐지 (7일 미접속)
- 업셀 기회 식별 (스킬 한도 도달)
- 월간 고객 건강도 스코어 계산

### 메시지 작성자 (A-CSM-002)
- 주간/월간 사용 리포트 작성
- 리인게이지 이메일 작성 (미접속 고객)
- 업셀 제안 메시지 작성
- 신규 기능 안내 메시지 작성
- 고객 성공 사례 작성

## 고객 건강도 지표
- **활성도**: 주간 세션 수
- **깊이**: 세션당 평균 메시지 수
- **다양성**: 사용 중인 스킬 개수
- **만족도**: 긍정적 피드백 비율
- **성장**: 월간 사용량 증가율

## 사용 Cloudflare 서비스
- **D1**: 고객 활동 로그 조회
- **R2**: 리포트 PDF 저장
- **Workers**: 자동화 스크립트

## Human Gate 조건

**할인/환불/계약 변경은 반드시 승인 필요**

- 이탈 방지 할인 제안
- 환불 처리
- 계약 기간 연장 협상
- 무료 스킬 제공

자동 리포트 발송은 승인 불필요.

## 워크플로우 예시

### 주간 리포트 자동 발송

```
매주 월요일 오전 10시 자동 실행
  ↓
[A-CSM-001] 전주 고객 활동 분석
  ↓
[A-CSM-002] 리포트 작성
  ↓
[A-CSM-002] 이메일 자동 발송
  ↓
고객 수신 확인
```

### 이탈 위험 고객 대응

```
[A-CSM-001] 7일 미접속 고객 탐지
  ↓
[A-CSM-001] 과거 사용 패턴 분석
  ↓
[A-CSM-002] 리인게이지 메시지 작성
  ↓
[A-CSM-002] 개인화된 이메일 발송
  ↓
응답 없을 시 전화 연락 (사람)
  ↓
[HUMAN GATE] 할인 제안 여부 결정
```

### 업셀 기회 발굴

```
[A-CSM-001] 스킬 한도 80% 도달 고객 식별
  ↓
[A-CSM-001] ROI 계산 (사용량 대비 요금제)
  ↓
[A-CSM-002] 업그레이드 제안 작성
  ↓
[A-CSM-002] 이메일 발송
  ↓
관심 표시 시 sales 팀에 인계
```

## 고객 세그먼트
- **파워 유저**: 일일 사용, 5개 이상 스킬 활용
- **일반 유저**: 주 2~3회 사용
- **저활용 유저**: 주 1회 미만 사용
- **이탈 위험**: 7일 이상 미접속
- **휴면**: 30일 이상 미접속

## 자동화 메시지
- **온보딩 완료 축하**: 첫 세션 후 24시간
- **첫 주 리포트**: 가입 후 7일
- **첫 달 리포트**: 가입 후 30일
- **미사용 스킬 안내**: 활성화 후 7일 미사용
- **리인게이지**: 7일 미접속
- **업셀 제안**: 한도 80% 도달
- **갱신 리마인더**: 계약 만료 30일 전

## 성공 지표 (KPI)
- **리텐션율**: 월간 활성 고객 / 총 고객
- **업셀 전환율**: 업그레이드 고객 / 제안 발송 수
- **이탈 방지율**: 리인게이지 성공 / 이탈 위험 감지
- **NPS**: 순추천고객지수
- **월간 반복 매출 (MRR)**: 증가율
