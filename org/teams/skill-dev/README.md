# Skill Dev 팀

## 미션
한국 시장 특화 AI 에이전트 스킬 개발 및 마켓플레이스 운영

## 소속 에이전트

| ID | 이름 | Claude Agent | 모델 | 역할 |
|----|------|-------------|------|------|
| A-SKL-001 | 스킬 설계자 | planner | Opus | 스킬 아키텍처 설계 |
| A-SKL-002 | 스킬 개발자 | executor | Sonnet | 스킬 코드 구현 |
| A-SKL-003 | 스킬 리뷰어 | code-reviewer | Opus | 스킬 코드 리뷰 |

## 담당 파이프라인
- **P-005: 스킬 개발 파이프라인**

## 주요 업무

### 스킬 설계자 (A-SKL-001)
- 고객/시장 요구사항 분석
- 스킬 기능 스펙 작성
- API 설계 및 인터페이스 정의
- 의존성 및 제약사항 분석
- 성능/보안 요구사항 수립

### 스킬 개발자 (A-SKL-002)
- TypeScript 기반 스킬 코드 작성
- Workers 환경 최적화
- 단위 테스트 작성
- 스킬 문서화 (README, API 레퍼런스)
- 샘플 코드 작성

### 스킬 리뷰어 (A-SKL-003)
- 코드 품질 검토
- 보안 취약점 점검
- 성능 병목 분석
- API 일관성 검증
- 배포 승인 여부 결정

## 한국 특화 스킬 예시
- **국세청 홈택스 연동**: 부가세 신고, 세금계산서 발행
- **정부24 연동**: 사업자등록증명, 법인등기부등본 조회
- **우체국 택배 추적**: 송장번호 조회 및 배송 알림
- **카카오 i 오픈빌더**: 카카오톡 챗봇 시나리오 연동
- **네이버 스마트스토어**: 주문 관리, 재고 동기화
- **쿠팡 판매자 API**: 상품 등록, 정산 조회
- **토스페이먼츠**: 결제 처리 및 정산
- **한국투자증권 API**: 주식 시세 조회

## 사용 Cloudflare 서비스
- **Workers**: 스킬 실행 환경
- **D1**: 스킬 메타데이터 저장
- **R2**: 스킬 패키지 저장
- **KV**: 스킬 설정 캐싱

## Human Gate 조건

**마켓플레이스 배포 전 반드시 승인 필요**

- 스킬 기능 스펙 승인
- 코드 리뷰 통과
- 보안 감사 통과
- 성능 테스트 통과
- 문서화 완료
- 가격 정책 확정

## 관련 매뉴얼
- [스킬 구성 매뉴얼](../../manuals/skill-config-manual.md)

## 협업 팀
- **persona**: 스킬 활성화 요청
- **integration**: 외부 API 연동 협력
- **platform**: 스킬 배포 파이프라인 관리
- **operations**: 스킬 사용량 모니터링
- **customer-success**: 스킬 개선 요청 수렴

## 워크플로우 예시

```
고객/내부 요청
  ↓
[A-SKL-001] 스킬 설계서 작성
  ↓
[HUMAN GATE] 설계 검토 및 승인
  ↓
[A-SKL-002] 코드 구현 및 테스트
  ↓
[A-SKL-003] 코드 리뷰
  ↓
수정 필요 시 개발자에게 피드백
  ↓
[A-SKL-003] 최종 승인
  ↓
[HUMAN GATE] 마켓플레이스 배포 승인
  ↓
마켓플레이스 등록
  ↓
persona 팀에 신규 스킬 안내
```
