# Sales 팀

## 미션
고객 획득 및 계약 성사를 위한 제안 활동 지원

## 소속 에이전트

| ID | 이름 | Claude Agent | 모델 | 역할 |
|----|------|-------------|------|------|
| A-SAL-001 | 제안서 작성자 | writer | Haiku | 고객 맞춤 제안서 작성 |
| A-SAL-002 | 요구분석가 | analyst | Opus | 고객 요구사항 분석 |

## 담당 파이프라인
- **P-001: 고객 획득 파이프라인**

## 주요 업무

### 제안서 작성자 (A-SAL-001)
- 고객 문의 내용 분석
- 업종/규모별 맞춤 제안서 생성
- 가격표/기능 비교표 작성
- 데모 시나리오 작성

### 요구분석가 (A-SAL-002)
- 고객 요구사항 구조화 분석
- 기술 실현 가능성 검토
- 커스터마이징 범위 산정
- onboarding 팀에 전달할 요구사항 문서 작성

## 사용 Cloudflare 서비스
해당 없음 (사람 중심 업무)

## Human Gate 조건

**모든 계약 및 가격 결정은 반드시 사람이 승인**

- 제안서 최종 발송
- 가격 할인/조정
- 계약 조건 변경
- POC 범위 결정

## 관련 매뉴얼
- 매뉴얼 없음 (세일즈는 사람 중심 프로세스)
- 제안서 템플릿: `org/templates/proposal-template.md`

## 협업 팀
- **onboarding**: 계약 후 고객 요구사항 전달
- **customer-success**: 기존 고객 업셀/크로스셀 협력
- **platform**: 데모 환경 요청

## 워크플로우 예시

```
고객 문의 수신
  ↓
[A-SAL-002] 요구사항 분석
  ↓
[A-SAL-001] 제안서 초안 작성
  ↓
[HUMAN GATE] 검토 및 승인
  ↓
제안서 발송
  ↓
[HUMAN GATE] 계약 협상 및 서명
  ↓
onboarding 팀에 인계
```
